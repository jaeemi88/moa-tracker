# 수강생 사후관리 트래커 (moa-tracker)

진로모아커리어센터 — 개인관리(수강생별 케어)와 진로모아관리(기관·실적 데이터) 두 축으로
운영되는 사후관리 앱입니다.

## 주소
- 강사용(기본): `moa-tracker.vercel.app?t=강사코드` — 처음 접속 시 강사 코드를 설정하면
  이후 같은 코드로 계속 접속합니다. 강사별로 데이터가 완전히 분리됩니다.
- 학생 설문(공개, 로그인 불필요): `moa-tracker.vercel.app?survey=1&t=강사코드&p=프로그램ID`
  — 프로그램 상세 화면에서 QR코드로 자동 생성됩니다.

## 주요 기능
1. **개인관리**: 수강생별 기본정보·상담 이력(타임라인)·다음 확인 예정일·취업 결과를
   추적합니다. 확인일이 지난 항목은 목록에서 "확인 필요"로 표시됩니다.
2. **진로모아관리**: 기관·프로그램별 실적(참여인원, 담당자, 재계약 의향)을 기록하고,
   상단 대시보드에서 협업 기관 수·누적 프로그램 수·누적 참여 인원·평균 만족도를
   한눈에 봅니다 — 제안서·사업실적 자료에 그대로 활용할 수 있습니다.
3. **QR 만족도 설문**: 프로그램마다 전용 QR코드가 생성되어, 강의 종료 직후 학생이
   로그인 없이 별점 3문항 + 한줄 코멘트로 30초 내 응답할 수 있습니다. 응답은 즉시
   해당 프로그램의 평균 만족도에 반영되어 진로모아관리 대시보드에 집계됩니다.

## 기술 구조
- Vercel + GitHub, Vercel Redis(ioredis)로 데이터 저장
- `api/students.js` — 개인관리 CRUD
- `api/programs.js` — 진로모아관리 CRUD
- `api/survey.js` — 익명 설문 응답 저장/집계
- 강사별 키 분리는 모의면접·자소서 첨삭 앱과 동일한 `t`(강사 코드) 방식
